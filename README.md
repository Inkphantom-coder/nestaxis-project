 NestAxis Premium Real Estate Portal

NestAxis is a high-fidelity, multi-page frontend web portal tailored for luxury property investments and capital management. Developed as a core academic project, this repository demonstrates semantic structure, modern responsive design systems, and custom client-side validation flows using vanilla web technologies.

 🌐 Live Deployment
The portal is fully compiled and accessible live on the web:
👉 **[Launch Live Portal Dashboard](https://inkphantom-coder.github.io/nestaxis-project/)**

 📂 Project Architecture & Directory Layout

The workspace is organized as a modular, flat-structure multi-page ecosystem to keep files highly maintainable:

```text
nestaxis-project/
├── index.html              # Main landing portal & secure authorization vault
├── register.html           # Partner onboarding and investment profile matrix
├── forgot-password.html    # Credential recovery initialization gate
├── verify-email.html       # One-time activation key transmission simulation
├── reset-password.html     # Security setting update portal
├── script.js               # Core interface engine & dynamic dashboard controller
└── assets/                 # Central repository for visual design layers
    ├── background.jpg      # High-fidelity architectural backdrop image
    └── logo.png            # Vector corporate identity asset
